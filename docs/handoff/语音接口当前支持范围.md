# 语音接口当前支持范围与请求样例

日期：2026年10月31日。适用版本：应用内部草案 `app-draft-1`。此文说明当前消费者实际接受的内容，尚未得到语音供应方确认，不是已完成的联合协议。

语音团队在 `services/speech/` 实现真实服务接入和结果转换。完整能力提案见[对接契约](../integration/语音模块对接契约.md)，配置和责任边界见[接入说明](语音结果接入说明.md)。应用运行后，`http://127.0.0.1:8000/docs` 和 `/openapi.json` 从当前代码生成接口定义。

## 写入入口与权限

向 `POST /api/integrations/speech/events` 发送 JSON 请求体，使用 `Authorization: Bearer <私有接入令牌>`。有效令牌只授予结果写入权限，不提供课堂列表、音频读取、音频上传、学生身份确认或报告发布权限。课堂须事先由授权教师创建，其标识由应用侧私下交接；不要新增无权限的课堂发现接口。

应用只接受 `upstream_live` 或 `recorded_result` 作为此入口的来源。只有实际实时处理结果才用前者，真实接口结果的记录回放用后者。下面是格式占位示例，不能直接发送后宣称已经完成真实联调：

```json
{
  "classroom_id": "替换为已创建课堂标识",
  "event": {
    "protocol_version": "app-draft-1",
    "session_id": "provider-session-001",
    "event_id": "provider-event-001",
    "sequence": 1,
    "event_type": "final",
    "source_kind": "recorded_result",
    "segment_id": "segment-001",
    "revision": 1,
    "start_ms": 0,
    "end_ms": 2200,
    "text": "替换为有使用权限的上游记录原话",
    "source_ref": "anonymous-source-01",
    "overlap": false
  }
}
```

成功响应为 `200` 和 `{"created":true}` 或 `{"created":false}`。前者表示存下新的原始事件，不保证该事件替换了当前发言；例如低修订号仍可留作原始记录。后者表示相同事件已接收，不能解读为丢包或必须换标识再发。

## 当前字段和约束

外层只接受 `classroom_id` 与 `event`；前者为1—80字符。内部字段如下，未列出的字段不接受。

| 字段 | 当前约束 |
|---|---|
| `protocol_version` | 仅 `app-draft-1`，省略时采用此值 |
| `session_id`、`event_id` | 必填，各1—80字符；会话和事件标识均由发送方稳定提供 |
| `sequence` | 必填非负整数；不是服务端返回的续传游标 |
| `event_type` | 必填：`partial`、`final`、`revision`、`withdraw`、`status`、`end` |
| `source_kind` | 必填；可信入口仅允许 `upstream_live`、`recorded_result` |
| `segment_id` | 发言类事件必填，1—80字符；同一片段修订保持标识 |
| `revision` | 大于等于1，默认1；为上游片段修订号，不是应用核验版本 |
| `start_ms`、`end_ms` | 非负整数，默认0，结束不得早于开始；相对于同一会话音频原点 |
| `text` | `partial`、`final`、`revision` 必填，去除首尾空白后1—6000字符；撤回可省略 |
| `source_ref` | 单个可空匿名标签字符串，最多100字符，不接受数组或坐标对象 |
| `overlap` | 布尔值，默认 `false`；不表示已交付分离音轨 |
| `status` | 状态事件必填：`running`、`paused`、`disconnected`、`ended` |
| `gap_start_ms`、`gap_end_ms` | 同时提供或同时省略；非负且结束不得早于开始，由发送方明确报告缺失区间 |

当前不支持独立的位置事件、音频可用事件、结构化坐标、多声源候选、`audio_ref`、`replaces` 或 `reliability_state`。这些提案内容直接发送将返回 `422`；实际需要时先共同确认扩展，不能偷偷压入 `source_ref` 字符串模拟已支持的类型。

## 重送、修订与结束

- 完全相同的 `(classroom_id, session_id, event_id)` 和请求内容重送，返回 `created:false`；相同标识改变任一事件字段返回 `409`。
- 较低片段修订号可记录原始事件，但不覆盖当前发言。新事件返回 `created:true` 不表示低版本已被采用。
- 相同修订号的临时结果，仅在 `sequence` 更大时更新；临时结果转定稿可以保持相同修订号。
- 相同修订号、相同非临时阶段必须具有相同的有效文字、时间、匿名声源、重叠和来源。变化须递增修订号，否则返回 `409` 并回滚该新事件。不同事件标识的完全相同快照可记录，但不增加应用版本或清除教师核验。撤回省略文字时，有效文字沿用原片段文字。
- 定稿之后改阶段也须递增修订号。事件是完整片段快照，不是只修改个别字段的补丁；未提供的可选字段会采用各自默认值。
- 当前没有独立创建语音会话接口。首个合法事件建立逻辑会话；`event_type=end` 封闭该会话，其后所有新事件标识返回 `409`，只有原事件完全相同的重送仍可幂等接收。
- `status=ended` 单独出现不封闭会话，发送方须在最终修订送达后发送 `event_type=end`。当前没有自动结束超时或结束后重新打开机制。

当前只校验 `sequence` 非负，不强制全会话连续、自动推断丢失范围或返回上游最后接收游标。应用事件列表按接收顺序保存；发送方须维护重试和续传记录，缺口用明确状态事件报告。真实重连能力仍须按 I06 联合验证。

## 错误码和排查

| 响应 | 当前含义 |
|---|---|
| `401` | 有效请求体下，接入令牌错误或缺失 |
| `404` | 写入开始前未找到目标课堂 |
| `409` | 来源为模拟、事件标识内容冲突、片段快照冲突，或会话结束后新增事件 |
| `410` | 初查之后课堂被删除，事务内拒绝迟到写入 |
| `422` | 请求字段、类型、枚举、时间约束或额外字段不合法；请求体验证可能先于鉴权执行 |
| `503` | 有效请求体下，应用未配置接入令牌或其长度不足32字符 |

原音频须另行交接：当前教师授权的 WAV 归档路径与结果写入权限分开，接入令牌不能代替教师上传。会话原音频不可覆盖。需要供应方自动上传或引用音频时，先确定受控交付通道及时间映射，不能仅增加一个当前不支持的 `audio_ref`。

本机采集诊断只归档音频，当前不会将采集帧转发给真实识别服务。来源、字段和错误码确认后，还须提供实际设备、服务、许可、正常及失败输出，并按[对接契约 I01—I09](../integration/语音模块对接契约.md#7联调验收)完成两种真实输入验证。
