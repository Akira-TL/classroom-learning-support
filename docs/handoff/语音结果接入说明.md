# 语音结果接入与采集诊断交接

当前提供应用内部草案 `app-draft-1` 的受控归一化结果入口，以及独立的音频采集传输诊断。尚未取得供应方账号、设备与真实协议验证；这两个入口的机械测试不能关闭真实语音联调任务 11。

## 接收归一化语音结果

语音团队将真实供应方输出转换为[当前支持范围与请求样例](语音接口当前支持范围.md)列出的实际字段，再通过 `POST /api/integrations/speech/events` 写入应用。请求体为 `classroom_id` 与 `event`，后者采用当前 `SpeechEvent` 类型，协议版本为 `app-draft-1`。[语音模块对接契约](../integration/语音模块对接契约.md)仍含尚未实现、待双方确认的目标字段，不能整份直接当作当前请求格式。不在应用中实现定位、转写或重叠分离算法。

请求头使用 `Authorization: Bearer <接入令牌>`。服务端从本机环境变量 `SPEECH_INGEST_TOKEN` 读取令牌；未配置或不足 32 字符时入口返回 `503`，鉴权失败返回 `401`。公开 `.env.example` 只保留空变量；真实值应通过双方约定的私有方式配置，不进入仓库、浏览器或公开交接记录。系统不自动生成或开启接入令牌。

该令牌只允许向已有课堂写入归一化语音结果，不能读取课堂、音频或发布教学报告；教师登录会话也不能替代接入令牌。事件来源只接受 `upstream_live`（真实上游结果）或 `recorded_result`（已记录结果），不能把回放标成实时。模拟事件仍走有教师授权的模拟入口，原教师事件入口仍拒绝自报 `upstream_live`。

同标识同内容重送返回 `created: false`；同标识不同内容或非法版本冲突返回 `409`。课堂不存在或已经删除时拒绝写入；取得写事务前发生删除也不会恢复孤立事件。写入结果仍是上游原文与匿名声源线索，文字、身份和题目三项教师核验保持独立。

教师可读取 `GET /api/integrations/speech/status`，得到 `endpoint_enabled`、协议版本和说明。`endpoint_enabled: true` 仅表示应用进程配置了符合长度要求的令牌，不表示供应方已连接、设备可用、音频已实际识别或定位通过。

## 音频采集传输诊断

`/api/classrooms/{cid}/input-sessions` 系列接口仅向授权教师开放，支持麦克风输入与文件按真实速度发送的采集侧数据路径。当前固定为 `capture_only`，`recognizer_connected` 始终为 `false`。输入为单声道、8—48kHz、`pcm_s16le`，每帧明确携带序号、起始样本、样本数及编码数据。

接收帧可以归档为可回听的原音频，但不会自动产生转写、定位、学生身份或证据，也不会自动调用上面的可信结果入口。重复与冲突帧、暂停、结束、中断和恢复均按接口类型及状态约束验证。删除课堂时一并清除采集会话、未归档帧及受控音频。

单声道格式仅用于这条采集诊断路径，不代表已确认供应方的定位输入格式。若定位设备或软件开发工具包需要多通道阵列音频，语音侧必须保留原始通道及同步信息；不能先混成单声道再声称验证了定位能力。

## 完成真实联调仍需要的交付

语音团队需提供实际服务端点与鉴权、设备型号和能力、采样格式与帧长、音频时钟、临时到定稿的修订规则、位置标签含义、结束及断流恢复行为、原音频及可选分离音轨。企业数据还需明确使用、公开演示、云端处理与删除许可。

两种输入均需实际经过真实语音服务，并按契约 I01—I09 留存正常、重叠、修订、断流和失败记录；只证明本机能够收帧或接收测试令牌事件，不算真实服务联调成功。
