# 领域文档约定

本项目采用单一上下文。探索前读取根目录 `CONTEXT.md`，并按主题读取 `docs/adr/` 中相关架构决策。

没有相关文件时继续处理，不为满足目录结构创建空文档。

`CONTEXT.md` 仅记录已确认、会在代码与需求中反复使用的项目概念，每项一至两句；不保存过程历史、技术实现或未解决问题。

没有既有 ADR 约定，采用 `docs/adr/NNNN-slug.md`。仅在决定难以撤回、缺少背景会令人困惑、且实际比较过替代方案时建立；格式参考 `domain-modeling/ADR-FORMAT.md`。

引用领域概念时使用词汇表名称。发现术语歧义先澄清，已有决定冲突则明确指出，不静默覆盖。
