日期：2026年10月31日。记录当前开发自检；未关闭真实重叠语音和完整前端验收。

## 运行与真实识别

- Windows 原生 Python 3.11.18、PyTorch 2.5.1+cu118；GPU 实际识别为 RTX 2060。
- CUDA 张量矩阵运算实际执行成功。没有安装 WSL 或改动显卡驱动。
- FunASR 模型加载成功，语音服务健康检查返回 `funasr-paraformer-zh`。
- 模型附带公开音频样例经实际语音服务生成文字，未使用按剧本返回的转写。
- 样例再通过应用的 `speech_stream` 输入进入服务，处理结束后待投递数为零，
  应用时间线收到 `upstream_live` 结果，保留原生声源和音轨引用。
- 教师授权音轨接口返回实际 WAV。测试创建的临时课堂已由脚本清理，未删除原演示课堂。
- 单声道只返回无法确定的声源线索，不将内部复制通道当作真实双麦方位。

以上证明单人样例的实际处理与回传链路，不能证明儿童课堂效果或两人重叠分离质量。
样例转写中存在词语误识别，没有据此计算识别准确率。
