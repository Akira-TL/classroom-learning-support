# 手指加减法课堂演示

日期：2026年10月31日。

## 页面入口

打开 `http://127.0.0.1:3000/`，选择教师，进入“手指加减法课堂”，打开“课堂详情”。
左侧点击学生，右侧查看上周、本周变化；切换教师、班主任、学生、家长、教导主任报告。
点击本周事件时间，可以定位并回听相应录音。

| 学生 | 主要对比 |
|---|---|
| 学生1 | 玩笔相关声音1→5次，另有移动板凳、掉笔等记录 |
| 学生2 | 咳嗽1→5次，新增打喷嚏1次、走神1次 |
| 学生3 | 打呼噜0→1次，拍桌0→6次，睡觉0→1次 |

报告位于视角切换控件下方，不经过教师确认或发布。
演示页面不展开制作说明；学习证据与练习仍沿用已认可的教师核验交互。

## 本机整理与复用

材料在忽略的 `data/private/recorded-demo-20261031/` 中，原件和转换记录保留。
应用可用播放文件为双声道16000Hz PCM16，2566161帧，160.3850625秒。
转写32段；声音报告26条，其中两个单点保留为单点，25条声音事件进入学生状态统计。

加法声音事件统一提前2000毫秒；减法从混音90000毫秒处开始，原时间先减4000毫秒，
因此减法声音事件统一增加86000毫秒。最后事件在159000毫秒结束，未超过音频。

重复导入命令：

```bash
bash scripts/import-recorded-demo.sh
```

命令通过既有应用接口写入，不直接修改运行数据库；相同材料和日期重复执行复用同一课堂、
发言和标签，不累计重复次数。学生归属及上周状态按当前演示设定生成。
