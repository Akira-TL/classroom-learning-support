## 已实际操作的浏览器路径

下列结果来自主 Agent 在本机应用中使用虚构演示账号的实际操作。开发者点击“确认”用于验证业务流程，不等同于用户已批准交互设计或真实教师已认可教学质量。

| 路径 | 实际观察 | 适用限制 |
|---|---|---|
| 学生反馈 | 教师发布反馈及练习，学生登录后读取本人报告并申请纠错；教师定位原发言、受理申请 | 受理申请不等于已修改事实；事实变更通过独立纠错操作完成 |
| 家长反馈 | 教师发布摘要及家庭活动，绑定家长读取并提问，教师回复 | 演示固定绑定 `parent-01` 与 `student-01`，不含学校账号同步 |
| 文件音频流 | 3 秒、16000 Hz、48000 样本的合成静音分成 12 帧接收，墙钟过程约 3.54 秒 | 仅为一次本机采集传输观察，不是性能承诺或识别时延 |
| DeepSeek | 真实生成学习证据、练习及教学安排，并进行人工数学内容修正及图形上下文不足检查 | 云端结果不会自动获得正确性认证，仍须教师核验与确认 |
| 管理者汇总 | 实际界面核对了分子／分母 1/1、0/0 显示为未定义，以及少于 5 人隐藏个人表现统计 | 说明这些演示分支已观察，不推导为所有筛选组合或学校部署均已验收 |
| 教师报告导出 | 实际生成编号前缀 `f6129b80` 的报告，受控下载成功；本机 HTML 源码检查包含图形比例 4:2:1:1、参考答案、版本及家长内容 | 浏览器安全策略拦截了 `blob:` 地址预览，不能将源码和下载检查计作视觉渲染通过 |

音频入口始终标记 `processing_mode=capture_only`、`recognizer_connected=false`；上述静音流没有验证语音转写、位置识别、说话人身份或重叠分离，也不构成思必驰真实联调。

生成内容中的数学答案、解释和图形需求必须逐项核实。生成成功只证明请求返回并通过数据格式检查，不证明教学判断正确；教师编辑稿、模型原稿和依据版本分别保留。

## 纠错与新版发布的实际记录

主 Agent 将原归属 `student-01` 修改为 `student-02`，发言有效版本由 4 更新为 5。预览显示受影响的证据、练习、教学安排、学生报告和家长报告各 1 项；操作后旧内容进入 `stale`，对应导出状态更新为版本 2、状态 `stale`。

随后分别以学生、家长账号核对旧报告：正文均已隐藏，原先疑问及教师回复仍可读取。此结果验证了本次纠错的角色访问行为，不表示已下载的离线文件能够远程收回。

再次修改文字并将归属改回 `student-01` 后，发言有效版本为 6。新的人工证据已保存并确认，再调用真实 DeepSeek 生成练习；练习保存为待核验版本 2，确认后版本 3，采用后版本 4。已发布新版学生报告（编号前缀 `4115009b`）和家长报告（编号前缀 `af32ad18`），旧版未恢复为有效内容。

新证据随后生成了新的教学安排，经补齐准备方式、备选安排和保留内容并核对检查方法后确认采用，记录合成检查结果至版本 4。新导出报告（编号前缀 `03098821`）为有效版本，原报告 `f6129b80` 仍保持失效。新旧内容并存用于演示纠错后的重新核验，未覆盖原模型输出。

## 删除验证的准确范围

主 Agent 另建一次性测试课堂，通过接口创建、归档音频和删除，并复送同一删除请求，返回同一任务；原有课堂集合未受影响。删除后的旧音频入口及迟到输入帧被拒绝，迟到帧返回 410。界面查询到任务为本机完成、供应方删除未请求。

本轮没有在浏览器中最终点击删除主演示课堂，也未完成浏览器中的文件清理失败后重试操作。这些界面路径仍待验证；独立后端测试中的删除与重试结果不能代替它们。

## 数据与公开范围

主运行数据库中的原演示课堂没有被删除，但其内容已按上述过程修正并发布新版。自动删除测试使用独立合成数据库；本机额外删除验证只操作一次性新建课堂，不能宣称主演示课堂已完成删除。

主运行数据位于 `data/private/`，日志位于 `logs/`，本机配置位于根目录 `.env`，比赛资料位于 `data/competition/`；这些路径被 Git 忽略。本文不记录密钥、演示密码、原始录音或企业数据内容。
