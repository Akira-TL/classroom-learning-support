## 规格决定

| 资料提示 | 项目决定 | 当前条件 |
|---|---|---|
| 思必驰生活办公方向包括基于智能终端的学校教育应用 | 保留教学闭环，记录企业资源在真实流程中的作用 | 按此方向准备，正式登记仍待用户核实 |
| DUI Open 提供语音技术接入入口 | 定位与转写仍归语音侧，教学应用只接入实际输出 | 未取得账号与实际服务 |
| Open-Bench 提及开发工具和业务数据 | 记录企业数据版本、来源、许可和具体用途 | 比赛专属数据未取得，不能声称已使用 |
| 未确定现场终端型号及输出协议 | 保持设备中立，不把普通麦克风等同于定位设备 | 拿到资料和实机后验证 |
| 通用交付要求区分现成组件与本次新增内容 | 提供代码、启动说明、真实演示证据及来源说明 | 纳入演示验收 |

核心价值仍是“学习证据 → 教师纠正 → 教学支持 → 反馈再核验”。成熟语音转写不作为本项目自行研发的创新点。资料作者的比赛策略不等同于官方强制技术条件；目前没有证据证明所有项目必须使用某一麦克风或某一数据集。

## 企业资源交接

语音侧交付终端实际型号、采集通道、音频格式、位置能力、时钟、转写接口和可复现样例。采集设备与语音处理服务分别记录，不能将普通麦克风演示标成已接入思必驰终端。

企业数据另记录提供方、数据集标识与版本、字段和标注含义、使用许可、公开演示许可、云端处理限制、保存期限及删除责任。原始文件与凭证保持本机私有；许可未知时不能自动发送至 DeepSeek。已批准的匿名合成教学数据仍可用于开发。

仅有转写标注、没有教学题目图形与人工参考的数据，可验证相应接入或语音指标，不能验证学习理解结论。没有位置标签也不能补造位置或学生身份。

## 演示约束

资料快照记载截止为北京时间 2026年11月1日 11:00，终评为 3 分钟介绍、2 分钟问答、最多 5 页演示文稿。提交入口和现场变动待用户核实；不据此删减已确认的完整闭环。

完整演示之外，准备可快速复位的核心操作：核验一条发言、检查证据、纠正归属、观察旧建议失效，再确认新版。预先生成材料明确标注为已记录结果，真实调用失败时显示失败。不自动代用户报名或提交作品。
