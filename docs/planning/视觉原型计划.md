# 视觉原型与前端演示计划

日期：2026年10月31日。状态：用户已确认 A 方向四张关键页面参考，完整前端已实施，正在验证。

## 用户已确定的流程

先开发应用功能，再通过 `imagegen` 生成三版效果图；用户选择方向、提出调整并确认后，以最终图稿作为完整前端的开发参考。三版图稿及实际提示词见[教师工作台三版视觉原型](../design/教师工作台三版视觉原型.md)。现已按确认的 A 方案实施前端，视觉核对状态见根目录[视觉核对记录](../../design-qa.md)。

## 三版图稿的比较方式

三版均展示同一课堂、同一题目和同一条待核验证据，便于比较信息层次和操作位置。最初比较时间线居中、题目与证据并排、按核验步骤组织三种方案；最终选择并确认时间线居中的 A 方向。

第一轮画面为教师核验工作台：课堂与来源状态、题目图形、发言时间线、文字与身份的分别核验、学习证据及其引用、待处理事项。界面使用中文，区分上游定稿、教师确认、证据待确认与已过期。

每版独立图片，保留生成提示词、生成方式、版本和文件位置。用户选定后才扩展已选方向，不将生成图片中的文字或虚构数字直接当作业务规格。

## 需覆盖的完整前端

| 页面 | 功能目标 |
|---|---|
| 课堂列表与创建 | 目标、题目图形、名单和输入来源可维护 |
| 教师核验工作台 | 时间线、回听、文字核验、身份核验、证据确认分别可操作 |
| 教学支持 | 编辑练习、提问安排和下一课调整，记录采用情况 |
| 发布与纠错 | 按接收对象预览、发布、撤回、处理反馈并说明失效原因 |
| 学生与家长 | 分别查看已发布的本人或绑定学生内容，反馈问题 |
| 管理者 | 授权汇总、资源需求及小样本隐藏提示 |

选定教师工作台方向后，按同一视觉规则补充其他页面与关键状态参考。正式开发须覆盖空数据、加载、失败、断流、信息不足、版本过期、权限拒绝和撤回状态；不能仅复现一张成功态截图。

用户选择 A 后，已补充[四张关键页面参考](../design/A方向关键页面参考.md)：教师工作台、教学支持、发布纠错及学生／家长／管理者页面。用户进一步确认这组布局并要求开始完整前端，确认前置条件已解除。
