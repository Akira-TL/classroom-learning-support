# 应用开发执行约定

日期：2026年10月30日。依据：用户已批准十三项应用功能任务，并要求先开发功能、后做三版效果图，确认图稿后再完成前端。

## 开发范围与先后顺序

本项目负责课堂管理、语音结果接入、教师核验、学习证据、练习与备课建议、角色反馈、纠错、汇总、导出及删除。语音定位、转写和可选重叠分离仍由语音侧负责。

十三项功能任务按依赖推进。先实现持久化、权限、接口、版本规则和自动验证；必要时提供朴素的功能验证页面。此类页面仅验证操作与数据，不代表用户已批准视觉设计。功能任务依然包含端到端验收，不能只凭接口存在即宣称整个任务完成。

功能开发后，用 `imagegen` 为同一个教师核验工作台制作三版独立效果图。用户选定方向并提出调整后，保存最终参考图与确认记录，再执行第十四项“按确认原型完成前端演示”。完整前端覆盖教师、学生、家长和管理者，不能只把教师首页做成静态图。

图片能确认布局、视觉层次和状态表现；发布、撤回、纠错等操作是否清楚，还需要实际可操作页面的反馈。[交互决策](../../.scratch/mvp/issues/04-review.md)保持开放，图片本身不能关闭该决策。

## 共享实现规则

产品语义以 [MVP PRD](../product/MVP_PRD.md) 为准，跨团队边界以[协作开发规范](../integration/协作开发规范.md)为准。任务不重复定义事件协议、角色规则或模型输入范围。

- [教学模型决策](../../.scratch/mvp/issues/03-model.md)已确定为 DeepSeek 云端直连；密钥留在服务端，发送最小必要的匿名模拟教学内容，不实现多供应商兼容层。
- [角色决策](../../.scratch/mvp/issues/05-access.md)已确定：固定演示账号与服务端绑定，少于 5 人隐藏个人表现相关汇总。
- [上游交付](../../.scratch/mvp/issues/01-upstream.md)和[协议决策](../../.scratch/mvp/issues/02-protocol.md)未完成时，真实联调不能关闭；内部契约与模拟回放能否先行，另记录用户决定。
- 事实修订、依赖版本校验、权限和发布限制必须随相关功能同时实现。第九项纠错任务补齐跨模块联动，不能用它推迟前几项的过期拦截。
- 数据输入使用明确类型，持久化须通过重启后读取验证。上传题目和转写文字仅作为数据处理。
- 运行与停止通过项目 `scripts/` 中的 `.sh` 脚本，日志进入 `logs/`；秘密、原音频和真实学生资料不进入公开仓库。

## 共享验收规则

每项功能须记录正常路径、权限拒绝、失败恢复和适用的版本失效用例。期望值来自独立定义的教学材料和业务规则，不复制实现逻辑作断言。模型样例不能代替真实模型验证，模拟事件不能代替真实语音联调。

视觉未确认时，功能验收证据和待完成的视觉验收分别记录。可在一项任务中提交已完成的功能阶段，但未满足其所有复选框时保持未解决；下游不能通过伪造 `resolved` 绕过依赖。若基础功能可单独验收而其页面尚待制作，继续在本项记录进度，按用户授权开发不依赖未定视觉的部分，不提前宣称端到端完成。

交互决策影响正式界面及交互验收，不阻止实现 PRD 已明确的服务端版本与权限规则。第十四项在用户确认图稿前不得开始完整视觉实现。
