# DeepSeek 教师功能联调

本次直接接入 DeepSeek 官方云端接口，不增加其他供应商兼容层。模型模块只提供待教师核验的证据分析与教学支持草稿；不承担账号授权、持久化、发布和课堂版本事务。正式接口接入时必须由服务端从已核验记录构造输入，不能信任浏览器自称已经确认。

## 本机运行

依赖在 `services/application/` 用 `uv sync --frozen` 安装，环境保存在该目录 `.venv/`。根目录 `.env` 包含 `DEEPSEEK_API_KEY` 和 `DEEPSEEK_MODEL`；公开示例只保留变量名，不包含密钥。

通过 Git Bash 执行 `bash scripts/run-model-demo.sh`。它仅对一条虚构的分数课堂发言发起真实分析，输出待确认草稿，然后退出；中途可按 Ctrl+C 停止。日志保存在被忽略的 `logs/deepseek-demo.log`。不会自动调用练习生成或发布学生报告。

自动验证：进入 `services/application/` 后运行 `uv run pytest`。测试使用受控的 HTTP 响应，验证协议和错误处理，不消耗真实模型额度，不作为教学质量验证。

## 输入、输出与失败

输入限定为已核验题目和匿名发言，身份、文字和题目确认分别表达。需要图形时必须提供教师核验的图形说明；当前文字路径不冒充视觉识别。结果为强类型对象，引用逐字匹配原话，练习覆盖三个层次并含答案与解释。

空结果、截断、无效结构、错误引用、鉴权失败、限流和网络错误明确返回失败。无自动重试和静默模拟回退，重试由操作者发起；应用层后续记录任务状态并在返回时重新检查输入版本。

参考：[DeepSeek 接入说明](https://api-docs.deepseek.com/)、[结构化输出](https://api-docs.deepseek.com/guides/json_mode/)。具体调用成功与否以本机实际联调记录为准。

本次只验证真实证据分析请求及响应校验；教学支持生成接口通过受控响应测试，尚未完成真实质量检查。身份授权、课堂持久化、输入版本变化后的失效事务和页面仍需后续应用任务实现，不能把这个模块当作已经完成的教师端。
