# 本机应用运行

当前交付为功能验证界面，尚非最终视觉方案。先完成接口与行为，再生成三版效果图供用户选择。

## 准备

后端：`uv sync --project services/application --frozen`。前端：在 `web/` 执行 `npm ci`。Node.js 使用本机现有 nvm 安装版本，不需 Visual Studio。依赖锁定文件随 Git 保存。

根目录 `.env` 配置 `DEEPSEEK_API_KEY`、`DEEPSEEK_MODEL` 和至少 12 位的 `DEMO_PASSWORD`。本机已生成演示密码，不在公开页面预填；从本机配置取用。缺失密码时服务拒绝启动。密钥和密码不放入前端或版本库。

## 启停

在两个 Git Bash 终端分别执行 `bash scripts/run-api.sh` 与 `bash scripts/run-web.sh`。打开 `http://127.0.0.1:3000`；接口文档在 `http://127.0.0.1:8000/docs`。日志进入 `logs/api.log` 和 `logs/web.log`，SQLite 数据库在 `data/private/classroom.sqlite3`。

停止可在终端按 Ctrl+C，或执行 `bash scripts/stop.sh`。停止脚本只处理固定端口中命令行属于当前工作目录的本项目进程，不停止其他占用者。所有服务仅监听本机，不代表已完成公网部署。

## 演示主体

教师 `teacher-01`、`teacher-02`；学生 `student-01` 至 `student-10`；家长 `parent-01` 固定绑定 `student-01`；管理者 `admin-01`。账号密码共用本机演示密码，角色与绑定由服务端决定，不能从浏览器任意提交角色获得权限。学生、家长和管理者的后续页面由各自任务继续实现。

## 当前验证

课堂创建、读取、修改与页面刷新已通过实际浏览器操作；6 项 API 测试验证持久化和权限、幂等及版本规则。前端通过 TypeScript 检查及 Next.js 生产构建。此记录不代表语音、完整教学闭环或最终视觉已经完成。

API 测试需要能够创建本机套接字的环境。测试临时目录应指定项目 `logs/` 下的独立目录，避免并行运行共用目录。测试和构建为非启停操作，直接使用 uv 或 npm 执行。
