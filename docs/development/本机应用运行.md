# 本机应用运行

当前前端包含课堂分析，以及左侧教室布局、右侧学生信息面板的课堂详情。
Chrome 已完成部分实际操作检查，完整范围见[原生语音与课堂详情实测](../verification/原生语音与课堂详情实测.md)。

## 准备

后端：`uv sync --project services/application --frozen`。前端：在 `web/` 执行 `npm ci`。Node.js 使用本机现有 nvm 安装版本，不需 Visual Studio。依赖锁定文件随 Git 保存。

根目录 `.env` 配置 `DEEPSEEK_API_KEY`、`DEEPSEEK_MODEL` 和语音接入令牌。
首页直接选择演示角色进入，不需要账号密码，也不要求配置 `DEMO_PASSWORD`。
旧密码接口仅保留已有测试调用用途。密钥不放入前端或版本库。

当前项目使用 Windows 默认文档目录，常见路径为 `%USERPROFILE%\Documents\ChatGPT\苏客松`。
PowerShell 可用下列命令进入实际文档位置，避免依赖旧 OneDrive 路径：

```powershell
Set-Location (Join-Path ([Environment]::GetFolderPath('MyDocuments')) 'ChatGPT/苏客松')
```

## 启停

在两个 Git Bash 终端分别执行 `bash scripts/run-api.sh` 与 `bash scripts/run-web.sh`。打开 `http://127.0.0.1:3000`；接口文档在 `http://127.0.0.1:8000/docs`。日志进入 `logs/api.log` 和 `logs/web.log`，SQLite 数据库在 `data/private/classroom.sqlite3`。

语音服务执行 `bash scripts/run-speech.sh`，监听 `127.0.0.1:8765`，日志位于 `logs/speech/server.log`。
依赖通过 `uv sync --project services/speech --frozen --extra asr --no-editable` 安装。
停止语音服务使用 `bash services/speech/scripts/stop.sh`。

停止可在终端按 Ctrl+C，或执行 `bash scripts/stop.sh`。停止脚本只处理固定端口中命令行属于当前工作目录的本项目进程，不停止其他占用者。所有服务仅监听本机，不代表已完成公网部署。

核对生产构建时，先通过上述方式停止开发服务，再执行 `npm run build --prefix web`，成功后运行 `bash scripts/run-web.sh production`；接口仍由 `scripts/run-api.sh` 启动。生产模式读取已生成页面，不进行开发热更新；修改源码后需重新构建。默认不传参数仍启动开发模式，日志和本机监听地址一致。

## 演示主体

首页提供教师、班主任、学生、家长、教导主任五种展示角色。
教师和班主任对应固定教师主体；学生可选择 `student-01` 至 `student-10`；
家长固定绑定 `student-01`；教导主任使用管理者汇总权限。
服务端维护演示身份、亲子绑定及会话视角，切换报告措辞不会扩大账号读取权限。

## OneDrive 中构建后重启的已知情况

2026年10月31日，生产构建通过后，开发启动因 `.next/static/` 内生成目录的 `readlink` 调用返回 `EINVAL` 退出。定向检查复现：Node.js 的 `readdir` 将该项报告为符号链接，而 `lstat` 将同一路径报告为普通目录；PowerShell也未发现链接目标。Next.js的递归清理按前一个结果调用 `readlink`，因此失败。

本次恢复先等待项目服务停止，核对 `.next` 的实际绝对路径及根目录不是链接，将其移至项目内被忽略的 `logs/frontend-build-468fcbe/` 保留，再用 `scripts/run-web.sh` 从空生成目录启动。随后显示就绪，首次页面编译完成并返回200。未移动源码、数据库或配置，未修改 Next.js依赖源码或 OneDrive 设置。

这是本次本机生成目录的恢复记录，不保证下一次构建后不会复发。若再次出现，应先检查实际目录类型和服务状态；仅处理已确认位于本项目内的生成目录，保留日志后再按项目脚本启动。不要在开发服务仍运行时并行生产构建，两者共同使用 `.next`。
