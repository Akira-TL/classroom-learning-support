# 独立语音模块开发入口

**语音团队在本目录开发。** 当前只建立协作入口，尚无已实现服务。

先阅读：

1. [协作开发规范](../../docs/integration/协作开发规范.md)：目录归属、分支、接口变更和联调流程。
2. [语音模块对接契约](../../docs/integration/语音模块对接契约.md)：输出字段提案及 I01—I09 验收。
3. [MVP PRD](../../docs/product/MVP_PRD.md)：教学应用如何使用语音结果。
4. [上游接入边界研究](../../docs/research/上游语音能力接入边界.md)：声源、时间和转写修订的注意事项。

当前可执行的应用入口另见[接入说明](../../docs/handoff/语音结果接入说明.md)与[实际支持范围和请求样例](../../docs/handoff/语音接口当前支持范围.md)。应用已有受控结果接收入口，但提案中的部分字段尚未支持；先核对实际字段、时间和结束语义，不直接照提案发送完整对象。后端运行后可从其 `/docs` 查看随代码生成的接口定义。

本模块负责现成定位与转写服务的接入、运行和结果交付；重叠分离与处理后音轨需先确认。教学判断、真实学生身份确认和角色报告由应用侧负责。

接手后先回复实际接口、部署方式与脱敏样例，再确认共享协议。随后在本目录建立代码、测试、模块依赖和启停脚本。不要将接口提案直接当作供应方现有能力。

交付时在本文件补充实际启动、停止、健康检查、配置方法及已知限制。未实现前不提供虚假的可运行命令。
