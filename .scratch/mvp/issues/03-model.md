## Question

学习证据解释和教学建议使用何种模型服务、部署位置与输入边界？在语音模型外接的前提下，比较本地、云端或混合方式，结合允许发送的数据、费用、结构化输出、失败恢复和数学质量作出选择。

结果包含选择、理由、所需凭证、数据最小化范围和可验证的质量条件，不下载或部署未批准的模型。

## Answer

2026年10月30日，用户明确指定 DeepSeek 云端模型，包括教师使用的大模型功能；不开发其他模型供应商兼容层。直接通过服务端调用 DeepSeek 官方接口，密钥仅保存在被 Git 忽略的本机配置，不发送给浏览器。

演示使用成人模拟资料。发送内容限于题目、教学目标、教师核验后的匿名发言及必要版本引用，不发送真实姓名、账号、原始录音与联系方式。未知身份不产生个人结论，缺图时提示补充而非猜测。

采用官方当前列出的 `deepseek-flash` 作为首次联调型号；同一供应商的具体型号可通过配置调整，不增加通用供应商接口。请求结构化输出并在本地校验；超时、空内容、截断和格式错误均作为失败，不自动切换模拟成功。未实现任务仍由应用任务跟踪，选择已确定不等于服务已验证。

质量条件：使用人工核对的分数题，检查引用、题干、答案和解释；教师确认后才生成后续建议和发布。接入试验只发起少量请求，不运行无人值守批量生成。

依据：[DeepSeek 官方接入说明](https://api-docs.deepseek.com/)、[结构化输出要求](https://api-docs.deepseek.com/guides/json_mode/)。
