# 教学应用开发任务

来源：[MVP PRD](../../docs/product/MVP_PRD.md)。执行与共享验收：[应用开发执行约定](../../docs/planning/应用开发执行约定.md)。

用户已批准十三项功能拆分；另按本轮要求记录确认效果图后的完整前端任务。任务属于教学应用团队，包含对应接口、数据行为、必要功能页面和验证；语音算法不在此范围。

| 编号 | 可独立验证的结果 | 本目录依赖 |
|---|---|---|
| [01](issues/01-classroom.md) | 教师创建和重新打开课堂 | 无 |
| [02](issues/02-timeline.md) | 回放结果并查看发言时间线 | 01 |
| [03](issues/03-verification.md) | 回听并核验文字、身份与题目 | 02 |
| [04](issues/04-evidence.md) | 生成、确认或驳回学习证据 | 03 |
| [05](issues/05-exercises.md) | 生成并编辑分层练习 | 04 |
| [06](issues/06-teaching-plan.md) | 提问安排、下一课调整与采用记录 | 04 |
| [07](issues/07-student.md) | 学生查看本人反馈并申请纠错 | 05 |
| [08](issues/08-parent.md) | 家长摘要发布、查看及撤回 | 04 |
| [09](issues/09-corrections.md) | 纠错触发全链路关联更新 | 06、07、08 |
| [10](issues/10-summary.md) | 管理者查看授权教学支持汇总 | 06 |
| [11](issues/11-speech-integration.md) | 两种输入完成真实语音服务联调 | 02 |
| [12](issues/12-export.md) | 导出经过核验的教师报告 | 06、08 |
| [13](issues/13-deletion.md) | 删除课堂及受控资源 | 03、07、08、12 |
| [14](issues/14-frontend.md) | 按用户确认原型完成四角色前端演示 | 01—13 |

表格仅索引，不代替每项任务的状态与跨目录前置条件。`ready-for-agent` 表示已发布，须核查任务阻塞和决策条件后才能领取；不表示所有事项都可立即执行。

三版效果图的制作和反馈见[视觉原型计划](../../docs/planning/视觉原型计划.md)，安排在功能开发后。未确认前可做功能与朴素验证页，不提前进行完整界面设计。
