# 09 — 纠错后的关联更新

**Source Spec:** [MVP PRD](../../../docs/product/MVP_PRD.md)，第 6 节及 M05、M09、M12；[共享执行约定](../../../docs/planning/应用开发执行约定.md)。

**What to build:** 教师处理纠错，将发言从学生甲改为乙或修改题目、文字后，所有相关证据、建议和报告正确失效，再核验和发布新版。

Blocked by: 06, 07, 08
Status: ready-for-agent
Claimed by: none

- [ ] 显示纠错影响范围及关联依据；甲和乙的个人内容均按实际依赖失效，无关记录保持有效。
- [ ] 关联证据与建议需重新核验；已发布旧报告立即停止提供，不能等待后台重生成才撤回。
- [ ] 人工编辑保留为注明依据变化的草稿，不静默丢弃或沿用确认状态。
- [ ] 旧任务晚到只能保留审计事实，不能覆盖更高版本或重新发布。
- [ ] 教师可完成重核、编辑、新版预览及发布；纠错申请保留处理结果。
- [ ] 在页面走通甲改乙及文字修订两种场景，并测试并发发布、旧任务返回和幂等重试。

前述任务各自的版本拦截必须已存在；本项补齐跨功能关联与完整纠错验收。
