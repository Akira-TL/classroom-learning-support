# 15 — 学生前后观察与关怀反馈

**Source Spec:** [MVP PRD](../../../docs/product/MVP_PRD.md)；2026年10月31日用户补充的演示口述内容。

**What to build:** 在已有教学闭环之外新增学生关怀入口，围绕同一学生不同时期的可核查记录，
供教师了解情况、记录跟进，并向本人及绑定家长发布不同的确认文字。

Status: claimed
Claimed by: /root

- [ ] 左侧学生选择，右侧上周与本周记录、来源、采集条件及教师跟进。
- [ ] 保留嘈杂原声，按同一时间范围回听可用的分离音轨；不以降噪为唯一展示目的。
- [ ] 观察绑定已确认学生身份的发言和版本；原始依据变化后旧反馈失效。
- [ ] 只比较同一学生自己的记录；没有测量值时不填音高或音量，不编造声音变化。
- [ ] 采集条件不同、样本不足和缺少历史记录均可见，不把它们解释为个人异常。
- [ ] 教师记录需要了解的情况及跟进；确认后按学生、家长分别发布。
- [ ] 服务端限制学生和家长仅查看本人或绑定对象的已发布文字，不开放其他人的音频。
- [ ] 演示材料明确标注成人模拟；真实处理与记录回放区分。
- [ ] 不把声音变化判为性格、健康或抑郁症，不自动向家长报备诊断。
- [ ] 不宣称未经实测的10人训练、全部声音事件识别或算法优越性。
- [ ] 关键版本失效与权限测试、真实页面交互验证记录完整。

咳嗽、掉笔等环境事件只有实际检测并核实后才显示。
当前语音服务是否能输出这些事件须以运行结果验证，不能用界面标签代替算法交付。
