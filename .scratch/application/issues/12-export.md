# 12 — 教师报告导出

**Source Spec:** [MVP PRD](../../../docs/product/MVP_PRD.md)，第 6、7 节及 M09、M12；[共享执行约定](../../../docs/planning/应用开发执行约定.md)。

**What to build:** 教师导出可阅读的课堂教学支持报告，包含已确认依据、建议与采用情况，并能识别文件版本与当前状态。

Blocked by: 06, 08
Status: claimed
Claimed by: /root

- [ ] 导出前再次验证教师授权、输入版本和确认状态；过期或未核验内容不可混入正式报告。
- [ ] 报告包括课堂、时间、版本、证据引用及教学支持，图形题内容完整可读。
- [ ] 生成失败可重试，不发布半成品；重复操作不产生不可追踪的版本。
- [ ] 下载入口受控；撤回、失效和删除后旧入口不可访问，状态查询不泄露报告正文。
- [ ] 文件说明离线副本不能远程撤回，读者需核对当前状态。
- [ ] 页面可预览并导出；验证导出时发生修订的竞争，以及权限和撤回行为。

不包含：自动给外部联系人发送报告。

## 功能阶段进度

2026年10月31日：教师报告导出服务端已接入课堂工厂，5项集成测试通过。导出为可打印的自包含HTML，内容来自当前已确认教学安排、教师编辑证据及可选有效家长报告，全部动态文本转义。每次下载复查权限、计划、证据和报告版本；撤回或依据变更后不再提供旧文件。公开状态入口仅返回随机标识、版本、时间、状态，不含正文和姓名。文件写失败不留下半成品入口，离线副本限制明确。页面、实际导出文件检查和用户使用尚待验证，本票不关闭。
