# 05 — 分层练习生成与编辑

**Source Spec:** [MVP PRD](../../../docs/product/MVP_PRD.md)，教学支持及 M07—M09；[共享执行约定](../../../docs/planning/应用开发执行约定.md)。

**What to build:** 教师从已确认学习证据获得概念巩固、解释表达和情境迁移练习，核对图形、答案与解释后编辑保存。

Blocked by: 04
Status: claimed
Claimed by: /root

- [ ] 每题包含题干、所需图形、答案、解释、练习目的和已确认依据。
- [ ] 首批图形与模板有人工核对记录，题目不缺图，不把未核实生成答案视为标准答案。
- [ ] 教师可修改、保存草稿、确认和撤销采用；编辑不会覆盖原始依据。
- [ ] 无可用依据或生成失败时可人工填写并明确来源，不伪造个性化建议。
- [ ] 依据变更后练习待重核，保留编辑草稿，过期练习不能直接发布。
- [ ] 通过页面完成一组练习的生成、修改和确认；验证数学样例、版本变化及重复操作。

不包含：学生练习反馈，交给任务 07。

## 功能阶段进度

2026年10月31日：分层练习的服务端生成、列表、编辑核验与采用已接入课堂工厂，6项集成测试通过。使用教师修订后的已确认证据；返回前事务重查，过期结果不变成有效练习，采用状态失效即清除。题干、答案和解释可编辑且保留原稿，三层次各一题。不依靠模型输出自动确认数学正确性。功能页、真实生成后的逐题核对与学生发布仍待后续验收，因此保持未解决。
