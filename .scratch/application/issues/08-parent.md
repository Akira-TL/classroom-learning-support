# 08 — 家长反馈发布与撤回

**Source Spec:** [MVP PRD](../../../docs/product/MVP_PRD.md)，四类角色及第 6 节、M10、M12；[共享执行约定](../../../docs/planning/应用开发执行约定.md)。

**What to build:** 教师为绑定家长预览并发布学习摘要与家庭活动建议，家长阅读、提交疑问；教师可撤回。

Blocked by: 04
Status: claimed
Claimed by: /root

前置规则：[角色授权与绑定](../../mvp/issues/05-access.md)。正式交互依据[交互决策](../../mvp/issues/04-review.md)。

- [ ] 摘要仅包含指定学生的已确认依据与适合家长的文本，不暴露其他学生及原音频。
- [ ] 教师可编辑、预览、发布和撤回；发布保存接收对象、版本与时间，重复发布无副本。
- [ ] 未确认、已过期或接收对象无有效绑定时，服务端拒绝发布和读取。
- [ ] 家长只读取绑定学生的有效报告，可提交关联报告的疑问供教师处理。
- [ ] 撤回立即使站内旧地址和受控下载失效；已下载文件不可远程收回的限制明确展示。
- [ ] 页面完整走通教师发布与家长读取；测试越权、撤回、重复请求和发布时版本竞争。

## 功能阶段进度

2026年10月31日：家长报告的预览、发布、读取、撤回和疑问处理服务端已接入课堂工厂，7项集成测试通过。发布学生强制匹配当前证据学生及服务端家长绑定，同一事务检查依据；撤回或纠错后家长旧链接立即410且不返回旧正文。当前摘要和家庭活动由教师人工填写，不冒称模型已经生成。前端与完整角色操作仍待验收，因此不关闭本票。
