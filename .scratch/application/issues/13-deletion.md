# 13 — 课堂删除与资源清除

**Source Spec:** [MVP PRD](../../../docs/product/MVP_PRD.md)，第 7 节及 M14；[共享执行约定](../../../docs/planning/应用开发执行约定.md)。

**What to build:** 授权教师确认删除课堂后，课堂音频、衍生片段、分析和报告不再可访问，清除进度与外部删除结果分别可追踪。

Blocked by: 03, 07, 08, 12
Status: claimed
Claimed by: /root

- [ ] 操作明确说明删除范围，并由服务端验证授权；未授权用户不能删除。
- [ ] 删除发起后立即停止所有受控读取和新任务，晚到生成结果不能恢复已删除课堂。
- [ ] 清除本项目持有的音频、衍生内容、分析和报告；失败可重试且不会误删其他课堂。
- [ ] 学生、家长和教师的旧链接均不能继续读取，既有离线副本限制明确。
- [ ] 对供应方记录未请求、处理中、成功或失败等事实；未取得回执不能声称外部删除成功。
- [ ] 审计仅保留必要操作事实，不借审计长期保存被删正文与音频。
- [ ] 页面展示清除状态，验证重复删除、部分失败、重试及后台任务竞争。

## 功能阶段进度

2026年10月31日：删除服务端已接入课堂工厂，删除及语音竞态共15项目标测试通过。先在事务内关闭并清除课堂及关联记录，再按受控资源清单逐文件清理；不递归删除，路径解析越界或失败保留可重试状态，不影响其他课堂。原始事件、核验、证据、练习、计划、两角色报告与反馈历史均清除，导出只保留匿名删除墓碑。模型返回、语音接收核验及音频归档都在事务中再次检查课堂存在，删除后晚到请求410，不恢复记录或返回旧结果正文。语音供应方删除状态为未发起，不声称已删远端或离线副本。界面及用户交互仍待接入，票不关闭。
