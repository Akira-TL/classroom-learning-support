# 11 — 真实语音服务联调

**Source Spec:** [MVP PRD](../../../docs/product/MVP_PRD.md)，M01—M04、M11；[语音契约](../../../docs/integration/语音模块对接契约.md)；[共享执行约定](../../../docs/planning/应用开发执行约定.md)。

**What to build:** 教师通过文件按真实速度回放和麦克风实时输入两种方式调用实际语音服务，结果进入已有课堂时间线。

Blocked by: 02
Status: ready-for-agent
Claimed by: none

前置决策：[真实供应方材料](../../mvp/issues/01-upstream.md)、[协议确认](../../mvp/issues/02-protocol.md)。缺少真实上游时保持阻塞，模拟结果不得满足本项验收。

- [ ] 两种输入实际进入语音服务，标注来源与模式，不绑定某个麦克风品牌。
- [ ] 记录供应方接口版本、采样与时间规则，实际事件经适配后符合内部契约。
- [ ] 验证正常、重叠标记、修订、重复、断流重连与结束；语音契约 I01—I09 留有可核对记录。
- [ ] 原音频引用能定位回听；可选分离音轨只在真实交付时展示，缺失能力明确说明。
- [ ] 麦克风授权拒绝、服务不可达和部分失败均可见，不悄悄切换为模拟成功。
- [ ] 原始录音、凭证和真实身份不进入公开仓库；记录可公开的脱敏验收摘要。
- [ ] 分别记录采集设备、语音服务及企业数据的实际来源、版本和许可；未取得资源明确标注，不冒称思必驰实机或企业数据已接入。

不包含：定位、转写或分离算法的开发与效果保证。
