正式交互验收依赖[核验交互决策](../../mvp/issues/04-review.md)；该决策不阻止先实现已明确的权限、记录和版本规则。

- [x] 能从时间线定位对应音频时间范围；音频缺失时说明原因，不展示虚假可播放状态。
- [x] 文字、身份和题目关联分别保存核验记录；上游定稿不自动完成教师核验。
- [x] 修改保留原上游输出、操作者及版本；声源标签不能未经确认变成学生身份。
- [x] 可标记无法判断；未确认的学生归属不进入个人证据输入。
- [x] 新修订保留人工编辑草稿并提示重核；旧版本确认请求被拒绝。
- [x] 受控音频仅对授权教师开放；自动验证越权、并发修订和无法判断路径。
- [ ] 朴素页面完成回听与分别核验，正式交互反馈仍记录在对应决策中。

## 功能阶段验收

2026年10月31日：13 项语音核验及音频 API 测试通过，包含教师编辑保留、仅改身份递增有效版本、旧核验拒绝、音频不可用、不可覆盖原音频、字节范围播放和多角色越权。主 Agent 浏览器分别确认文字、身份、题目，保存后应用版本从 3 变为 4；上传本机生成的 3 秒静音 WAV，出现受控播放入口且实际加载播放成功。静音样例只验证归档与播放链路，不代表与文字相符的语音材料或上游质量。

功能页已可操作，但用户尚未实际反馈核验交互；按原有前置条件保留未解决状态，后续完整前端确认时收敛交互决策。原始音频限 PCM WAV、20MB、10 分钟以内；会话0毫秒对应文件起点，时间超出范围拒绝回听。
