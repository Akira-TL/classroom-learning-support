# 03 — 回听与教师核验

**Source Spec:** [MVP PRD](../../../docs/product/MVP_PRD.md)，教师核验工作台及第 6 节；[共享执行约定](../../../docs/planning/应用开发执行约定.md)。

**What to build:** 教师从发言定位可用音频片段，分别核对文字、学生归属和题目关联，并能标记无法判断。

Blocked by: 02
Status: ready-for-agent
Claimed by: none

正式交互验收依赖[核验交互决策](../../mvp/issues/04-review.md)；该决策不阻止先实现已明确的权限、记录和版本规则。

- [ ] 能从时间线定位对应音频时间范围；音频缺失时说明原因，不展示虚假可播放状态。
- [ ] 文字、身份和题目关联分别保存核验记录；上游定稿不自动完成教师核验。
- [ ] 修改保留原上游输出、操作者及版本；声源标签不能未经确认变成学生身份。
- [ ] 可标记无法判断；未确认的学生归属不进入个人证据输入。
- [ ] 新修订保留人工编辑草稿并提示重核；旧版本确认请求被拒绝。
- [ ] 受控音频仅对授权教师开放；自动验证越权、并发修订和无法判断路径。
- [ ] 朴素页面完成回听与分别核验，正式交互反馈仍记录在对应决策中。
