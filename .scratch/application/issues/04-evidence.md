# 04 — 生成并确认学习证据

**Source Spec:** [MVP PRD](../../../docs/product/MVP_PRD.md)，学习证据要求及 M06、M07、M09、M11；[共享执行约定](../../../docs/planning/应用开发执行约定.md)。

**What to build:** 教师针对已核验发言生成或录入学习证据，检查原话、题目与解释，再确认或驳回。

Blocked by: 03
Status: claimed
Claimed by: /root

前置决策：[模型与数据边界](../../mvp/issues/03-model.md)。模拟生成必须显式标注，不能作为真实模型验收。

- [ ] 输入包含已核验发言、身份、题目上下文和版本；缺少必要图形时提示补充。
- [ ] 每项证据可回溯到题目与发言版本，区分原话、解释、限制和教师判断。
- [ ] 教师可确认、驳回、补充说明，系统不以发言次数或声音位置判定掌握程度。
- [ ] 生成失败可重试，已收数据和人工修改不丢失；输出格式不合格不能成为已确认记录。
- [ ] 任务运行期间依据发生变化，旧结果不能覆盖现有状态；重新核验前禁止发布。
- [ ] 页面呈现待确认、驳回、信息不足、失败和过期状态；自动验证这些状态。
- [ ] 使用经人工核对的分数题作为独立参考，记录真实模型或模拟模式及验证范围。
