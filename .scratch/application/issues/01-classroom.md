# 01 — 教师创建课堂

**Source Spec:** [MVP PRD](../../../docs/product/MVP_PRD.md)，第 4、5、7 节；[共享执行约定](../../../docs/planning/应用开发执行约定.md)。

**What to build:** 教师以本人身份创建课堂，填写目标、名单和带图形的题目；保存后重新打开仍能继续准备课堂，其他教师不能访问。

Blocked by: none
Status: resolved
Claimed by: /root

前置决策：[角色授权](../../mvp/issues/05-access.md)。固定演示账号的实际访问校验不能由浏览器角色选择代替。视觉完善交给任务 14。

- [x] 登录主体可创建、列出、读取和修改本人授权课堂；另一教师直接访问被拒绝。
- [x] 课堂保存名称、日期、教学目标、虚构学生名单、来源与授权说明；题目包含稳定标识、题干及所需图形。
- [x] 必填和无效关联得到明确错误；重复提交不产生重复课堂。
- [x] 重启应用后内容和所属教师保持一致；未授权角色不能修改。
- [x] 朴素验证页面可完成创建、打开、修改；不包含未获确认的完整视觉设计。
- [x] 自动验证持久化、重复提交与越权；验收证据注明演示账号模式。

不包含：真实学校账号同步、语音处理及学习证据生成。
