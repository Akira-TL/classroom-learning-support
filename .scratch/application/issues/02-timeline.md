# 02 — 回放语音结果并展示时间线

**Source Spec:** [MVP PRD](../../../docs/product/MVP_PRD.md)，M02、M03、M04、M11；[共享执行约定](../../../docs/planning/应用开发执行约定.md)。

**What to build:** 教师打开课堂，播放已记录或合成的语音事件，看到逐步更新的发言时间线、来源与接收状态。

Blocked by: 01
Status: resolved
Claimed by: /root

前置决策：[协议](../../mvp/issues/02-protocol.md)。如用户批准内部草案先行，按明确记录的草案版本实施；外部协议与真实联调仍不得标为完成。

- [x] 结果回放支持开始、暂停、继续，准确标注为已记录结果或模拟事件。
- [x] 临时文本、上游定稿及修订更新同一发言，保留版本与时间范围。
- [x] 重复事件无重复记录；低版本和乱序事件不能覆盖较新内容。
- [x] 声源标签与真实学生身份分开；缺失区间和断流可见，不推断学生沉默。
- [x] 保存后重开课堂可还原时间线与来源；无权限主体不能注入事件或读取课堂。
- [x] 页面可观察回放、重复、修订和断流样例；自动验证各类事件的确定期望结果。

不包含：真实语音服务接通、语音模型和音频分离；任务 11 完成实际接入。
