# 06 — 提问安排与下一课调整

**Source Spec:** [MVP PRD](../../../docs/product/MVP_PRD.md)，教学支持及 M07、M09、M13；[共享执行约定](../../../docs/planning/应用开发执行约定.md)。

**What to build:** 教师根据已确认证据制定提问安排与下一课活动调整，编辑后记录是否采用及后续检查结果。

Blocked by: 04
Status: claimed
Claimed by: /root

- [ ] 提问建议包括对象、问题、准备方式和备选安排；不确定时作为补充检查，不作确定判断。
- [ ] 下一课调整包括保留内容、调整活动、依据及检查方法。
- [ ] 教师能编辑、确认、采用、撤销采用并记录后续观察；原备课资料保持可追溯。
- [ ] 所有个人建议引用有效证据；依据过期时标记重核，不继承旧确认。
- [ ] 生成失败与部分完成可重试，人工编辑不被后台返回覆盖。
- [ ] 页面可完成建议到采用记录的完整路径；自动验证权限、失效和重复操作。

## 功能阶段进度

2026年10月31日：教学安排服务端已接入课堂工厂，6项集成测试通过。模型初稿提供提问、活动和检查方式，准备、备选及保留内容明确留给教师补齐，未补齐时不能确认或采用；个人安排对象必须匹配证据学生。教师编辑与原稿分别保存，支持采用、撤销与后续检查记录；依据过期清除采用状态，保留编辑和观察记录。界面尚待主 Agent 接线和真实操作验收，本票未关闭。
