# 07 — 学生反馈与纠错申请

**Source Spec:** [MVP PRD](../../../docs/product/MVP_PRD.md)，四类角色及 M09、M10、M12；[共享执行约定](../../../docs/planning/应用开发执行约定.md)。

**What to build:** 教师预览并发布学生反馈及练习；学生查看本人内容、记录练习反馈并申请纠错，教师可看到处理队列。

Blocked by: 05
Status: claimed
Claimed by: /root

前置规则：[角色授权](../../mvp/issues/05-access.md)；学生发布流程须满足独立接收对象和版本校验。

- [ ] 教师发布前可按学生预览，服务端校验归属、确认状态、依据版本和接收对象。
- [ ] 学生仅能读取本人有效已发布内容，直接替换标识访问他人资源也被拒绝。
- [ ] 不开放包含他人声音的音频，不暴露未发布证据和教师内部备注。
- [ ] 学生提交练习反馈或纠错请求，保留关联报告版本及处理状态；重复请求不重复建单。
- [ ] 教师可查看、受理或说明驳回；修改事实的全链路联动由任务 09 验收。
- [ ] 撤回或依据过期立即阻断旧内容读取，页面提示等待新版。
- [ ] 双角色页面可走通发布、查看、反馈，自动验证越权和失效访问。

## 功能阶段进度

2026年10月31日：学生报告预览、发布、本人读取、撤回、练习反馈和纠错受理服务端已接入课堂工厂，5项集成测试通过。发布包含教师编辑并确认的练习快照和反馈；同事务检查练习及证据版本。其他学生和角色不能读，失效或撤回后正文410，列表只保留元数据。反馈携带原报告版本且幂等，教师处理保留历史；纠错事实的全链路更新由09继续验收。功能页面未接入，本票不关闭。
